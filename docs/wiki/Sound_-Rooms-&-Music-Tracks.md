## Room Music

Address `0x020FB328` holds a pointer to a count and an array of 71 structs describing room music. The music values are indices into the global music struct array, which can provide different values concerning the music "layers" given the same room ID. This data is loaded from `data/sound/ASSIGNMUSIC.DAT`.

In 1P mode, the first track is used initially, and the second track is used once the area's boss has been defeated. In multiplayer mode, the first track is used normally, the second track is used while an an Octolith is being carried in Capture or Bounty modes, and the third track is used while capturing a node in Nodes mode.
